# Kafecito

## Descripción

**Kafecito** es un proyecto de Kotlin en consola (CLI) que simula el sistema de gestión de una cafetería, aplicando conceptos de Programación Orientada a Objetos (POO).

El sistema permite gestionar usuarios, productos, inventario y pedidos, además de generar diferentes reportes.

## Funcionalidades

- **Usuarios:** registro, inicio de sesión y roles de Administrador, Empleado y Cliente.
- **Productos:** agregar, listar, buscar y filtrar productos, además de controlar su disponibilidad.
- **Inventario:** registrar y actualizar stock, consultar existencias y detectar stock bajo.
- **Pedidos:** realizar pedidos mediante un carrito de compras y actualizar su estado.
- **Reportes:** consultar ventas, pedidos, productos más vendidos, inventario y resúmenes por categoría.

## Tecnologías

- Kotlin
- Consola (CLI)
- Programación Orientada a Objetos (POO)
